# 1 Proposta
O primeiro passo para escolher o projeto foi pegar algo próximo a minha realidade, como ex-morador de Mauá peguei o ultimo conjunto de dados disponível do município para efetuar análises dos gastos e receitas da cidade que morei naquele ano. 
Uma temática importante é saber como está sendo gasto o dinheiro de onde moramos e quais melhorias estão sendo trabalhadas nelas. A análise de dados pode ajudar a manter o foco do que podemos esperar ou podemos ir à câmara municipal propor projetos de melhorias.

## Fonte
https://transparencia.tce.sp.gov.br/municipio/maua
São dados estruturados do portal da transparência com download Direto


## EDA
A exploração inicial e estrutura foi feita no VScode usando python.
A análise inicial mostrou um alto valor de registros nulos nas tabelas no qual iremos explorar os valores encontrados de forma visual no Looker Studio
O arquivo e as saídas do Script Python estão em uma pasta separada neste repositório.

### Link para o Looker

### Conclusões
Após as análises gráficas de valores arrecadados e gastos, podemos concluir que o município de Mauá foi deficitário no ano de 2020, a cidade dependeu muito dos repasses do estado e da União para sua renda somando 52,9%. 
Os gastos com gestão e qualidade em um único mês deu em média 10x mais a arrecadação anual durante todos os meses do ano, isso sem contar todos os outros gastos da cidade. Estudos mais detalhados sobre para onde essa verba serão necessários. Mesmo o mês de janeiro e Fevereiro ainda não havendo o Lockdown e toda a crise da pandemia que atingiu o país o resto do ano.
